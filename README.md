# Auto-Clicker
This is a project I created where you can run a programme for auto-clicks at a selected frequency (clicks/second). My auto-clicker also has a delay between clicks to bypass certain restrictions (e.g. in games) and make the clicks look very realistic. 


🖱️ Python Auto Clicker
Простий та ефективний автоклікер з графічним інтерфейсом, побудований на базі бібліотеки Tkinter. Програма дозволяє автоматизувати натискання лівої кнопки миші з точно налаштованою швидкістю.

✨ Особливості
Налаштування швидкості: можливість вказати точну кількість кліків на секунду.

Гарячі клавіші:
Швидка зупинка та вихід за допомогою клавіші ESC.
Перегляд інформації про програму натисканням клавіші i.
Інтуїтивний інтерфейс: Чистий дизайн у приємних тонах із використанням шрифту Trebuchet MS.
Безпека: Вбудована перевірка введення, що запобігає некоректній роботі при помилкових даних.

🚀 Як запустити
Встановіть необхідні залежності: для роботи програми потрібні бібліотеки mouse та keyboard. Встановіть їх через pip:
Bash
pip install mouse keyboard
Примітка: для роботи бібліотек mouse та keyboard у деяких ОС можуть знадобитися права адміністратора.

Запустіть скрипт:
Bash
python auto-clicker.py

🛠️ Використання
У полі "Клики в секунду" введіть бажану швидкість (за замовчуванням встановлено 10).
Натисніть кнопку "Старт".
З'явиться підтвердження запуску. Щоб зупинити роботу програми та вийти, натисніть клавішу ESC або кнопку "Выход".

⚠️ Важливі зауваження
Швидкість: значення має бути числом більше нуля.
Зупинка: програма автоматично припиняє роботу при закритті вікна або натисканні гарячої клавіші виходу.

⚙️ Технічний стек
GUI: tkinter.
Контроль миші: бібліотека mouse.
Обробка клавіш: бібліотека keyboard.
Логіка циклу: метод root.after() для стабільної частоти кліків без заморожування інтерфейсу.
